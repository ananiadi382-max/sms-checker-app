# 📱 Проверка номеров: HLR + Ping

Веб-приложение для проверки телефонных номеров через API SMSC.ru:
двумя независимыми способами — по отдельности или вместе.

## 🚀 Возможности
- **HLR-проверка** — существует ли номер у оператора (1,60 руб./проверка)
- **Ping-проверка** — включён ли телефон прямо сейчас (от ~6,50 до ~12 руб./проверка, зависит от оператора)
- Проверка одного номера, списка номеров или загрузка Excel-файла
- Простая таблица "для сотрудника" (Номер / Существует / В сети / Активен) с подсветкой строк
- Защита от случайного повторного платного Ping по одному номеру (cooldown с подтверждением)
- Экспорт результатов в CSV/Excel — отдельно упрощённый вид и отдельно полные технические данные

## ⚙️ Настройка

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. **Логин и API-ключ SMSC настраиваются один раз администратором и не видны сотрудникам**, которые пользуются приложением:
   - **На Streamlit Cloud:** в панели приложения → *Settings → Secrets* — вставьте содержимое `secrets.toml.example` с реальными значениями. Сотрудники, открывающие ссылку на приложение, ключ не увидят и вводить его не будут.
   - **Локально (для админа/разработчика):** скопируйте `secrets.toml.example` в `.streamlit/secrets.toml` (или используйте `.env` по образцу `.env.example`) и впишите реальные значения.
   - Если ключ нигде не настроен, в приложении появится предупреждение и временная возможность ввести его вручную — это запасной вариант для разовой проверки, не для повседневной работы сотрудников.
3. Запустите приложение:
   ```
   streamlit run app.py
   ```

## 📂 Структура проекта

```
app.py                  - интерфейс Streamlit
utils/smsc_api.py       - обёртка над HTTP API smsc.ru (HLR, Ping, баланс)
utils/file_processor.py - извлечение номеров из Excel, форматирование результатов
requirements.txt        - зависимости
```

## ⚠️ Важно

- Логин/API-ключ вводятся как пароль (не сохраняются в коде) — никогда не коммитьте их в репозиторий.
- Каждая проверка тарифицируется реальными деньгами на балансе SMSC.
